プライバシーポリシー

zzZombie Leaders（以下「本アプリ」）は、JunriceDevが個人で開発・運営しています。本アプリとそのサポートサイトでは、次の方針で情報を取り扱います。

1. 端末内に保存する設定

音量、照準補助、射撃の押し込み、操作案内を確認したかどうかなど、利用に必要な設定を端末内に保存します。運営者の独自サーバーへ、これらの設定を送信する処理は設けていません。

2. Game Centerとオンライン対戦

オンライン対戦にはAppleのGame Centerを使用します。認証、対戦相手の照合、招待、接続のために、Appleが提供するプレイヤー識別情報等を利用します。対戦中は、操作、位置、HP、ゾンビの所属、試合結果など、対戦の進行に必要な情報を相手端末と送受信します。

Game Centerの情報を広告向けの識別子として渡す処理は設けていません。Appleによる情報の取り扱いは、Appleのプライバシーポリシー等をご確認ください。

3. 広告配信

本アプリはGoogle AdMobの広告SDKと同意管理機能を利用します。広告の表示・計測・不正利用防止等のため、Googleおよび広告配信に関わる事業者が、IPアドレス、端末やアプリに関する識別情報、広告の表示・操作情報、診断・パフォーマンス情報などを処理する場合があります。IPアドレスから、おおまかな地域が推定されることがあります。

本アプリは非パーソナライズ広告を要求する設定とし、Google SDKのパブリッシャーのファーストパーティID機能を無効にします。こうした設定でも、広告の配信や安全性確保に必要な情報が処理されることがあります。

情報の処理は、端末設定、同意の選択、地域、Googleのサービス仕様等により異なります。詳しくはGoogleのプライバシーポリシーとGoogleのサービスを使用するサイトやアプリから収集した情報の使用方法をご確認ください。

4. トラッキングを行わない広告とプライバシーの選択

本アプリは、他社のアプリやWebサイトでの行動履歴と結び付けた広告配信・広告測定のためのトラッキングを行わない構成で運用します。広告のパーソナライズと、広告SDKのパブリッシャーのファーストパーティID機能を無効にし、広告識別子（IDFA）の利用許可は要求しません。Game Centerの情報を広告に渡す処理もありません。

非パーソナライズ広告でも、広告の回数制御・集計・不正利用防止等のためにCookieや端末情報の保存・利用について同意が必要となる場合があります。欧州経済領域（EEA）・英国・スイスなど、地域と同意状態に応じてGoogleの同意画面を表示します。この画面はAppleのトラッキング許可を求める画面ではありません。同意しても、本アプリの広告をパーソナライズ広告へ切り替えることはありません。

「同意しない」を選んでもゲームを利用できます。「設定・操作案内」に「広告のプライバシー設定」が表示される場合は、その項目から選択を変更・取り消しできます。広告を要求できる状態を確認できない場合も、ゲームの利用を継続できるようにします。

5. お問い合わせ

お問い合わせいただいた場合、送信元メールアドレスと本文・添付資料に含まれる情報を、調査、回答、サポート対応のために利用します。パスワードや認証コードを求めることはありません。ご連絡内容に不要な個人情報を含めないようお願いいたします。

6. 情報の開示等に関するご請求

当方が保有する個人データの開示、訂正、利用停止等に関するご請求は、下記の連絡先へお寄せください。ご請求の内容を確認し、必要に応じてご本人であることを確認したうえで、法令に従って対応します。

確認の結果、ご請求の対象となる情報を当方が保有していない場合は、その旨をお知らせします。AppleやGoogle等の外部サービスが管理する情報については、内容に応じて各社の窓口や手続きをご案内する場合があります。

7. サポートサイト

このサポートサイトは静的なHTML・CSS・画像だけで構成し、CookieやWebストレージを書き込む機能、Cookie同意バナー、広告、アクセス解析、トラッキング用スクリプトを設置していません。アプリ内のGoogleの広告同意画面と、このサイトは別のものです。

サイトの配信にはGitHub Pagesを利用します。GitHubは、安全性確保のためにサイト訪問者のIPアドレスを記録・保存します。詳しくはGitHubのプライバシーステートメントをご確認ください。Apple・Google等の外部リンク先では、各社のポリシーが適用されます。

Privacy summary in English

This app requests only non-personalized ads. It does not track users across other companies' apps or websites for advertising or advertising measurement. Ad personalization and the publisher first-party ID feature are disabled; the app does not request IDFA access or share Game Center identifiers with the ad SDK.

In the EEA, UK and Switzerland, Google's consent message may ask about device storage/access for ad frequency limits, aggregate reporting and fraud prevention. This is separate from Apple's App Tracking Transparency permission. Refusing consent does not block gameplay. Privacy choices can be revisited in the app settings when required.

This static support website does not set cookies or web storage, display a cookie banner, run advertising or analytics, or load tracking scripts. GitHub Pages may retain IP addresses for security as described above. The policies of Apple, Google and GitHub apply to their respective services.
